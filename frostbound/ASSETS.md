# Frostbound visual asset manifest

This build intentionally uses photographic scenery and imported GLB assets instead of rebuilding the rejected primitive visual style.

## Photographic scenery

- Aurora / snowy mountain village backdrop: Unsplash photo `photo-1593378026483-2a1fd46a35bd`.
- Snowmobile action loading artwork: Unsplash photo `photo-1709881628099-8b4574ca3709`.

These photos are used as cinematic scenery/art layers and are **not** presented as screenshots from the running game.

## 3D assets

Runtime-loaded from 3DAssets.dev:

- Hero snowmobile: `https://cdn.3dassets.dev/assets/28491/v1/model.glb`
- Alpine Snow Village starter scene: `https://cdn.3dassets.dev/assets/19850/v1/model.glb`
- Winter rider source: `https://cdn.3dassets.dev/assets/18919/v1/model.glb`
- Large snow kicker: `https://cdn.3dassets.dev/assets/25972/v1/model.glb`

3DAssets.dev publishes these web-optimised GLB assets under CC0 and supports direct CORS-enabled GLTFLoader loading.

## Acceptance rule

A source photo is never a substitute for a real in-game screenshot. Final acceptance still requires browser execution and screenshots captured from the rendered game itself.
